OVERVIEW:
This project is an AI-powered decision-support system designed to help Indian retail investors make informed investment decisions.

With over 14 crore demat account holders in India, many investors rely on tips, lack understanding of technical indicators, and struggle to interpret financial data. Platforms like Economic Times Markets provide vast data, but it is not always actionable.

This system acts as an intelligence layer that converts raw market data into simple, personalized, and explainable investment insights.

FEATURES:
-Fetch real-time stock data
-Analyze stock trends (Uptrend/Downtrend)
-Risk analysis based on volatility
-User profiling (risk level, budget, duration)
-AI-based recommendation (Buy / Hold / Avoid)
-Explainable insights (reason behind recommendation)
-Modular architecture for scalability

Technologies / Tools Used:
Programming Language: Python
Libraries:
yfinance – stock data retrieval
pandas – data handling
numpy – numerical analysis
Version Control: Git & GitHub

Installation & Setup:
Step 1: Clone the repository
git clone https://github.com/your-username/ai-investor-assistant.git
cd ai-investor-assistant
Step 2: Install dependencies
pip install yfinance pandas numpy
Step 3: Run the project
python main.py
